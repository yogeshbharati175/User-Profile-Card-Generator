# User Profile Card Generator

Python Flask project for server-side form processing, dynamic profile-card rendering and SQLite database storage.

## Features
- Name, Bio, Skills and Social Links form
- Server-side processing with Flask
- Dynamic HTML using Jinja2
- SQLite database
- View and delete saved profiles
- Responsive UI

## Run
```powershell
python -m venv venv
.\venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python app.py
```
Open http://127.0.0.1:5000
